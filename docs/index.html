Windows 便携版

下载 MyMemoBoards-1.0.0-portable.exe，双击即开。数据生成在 exe 同目录 data/。

Windows 安装版

下载 MyMemoBoards-1.0.0-setup.exe，安装后开始菜单 / 桌面快捷方式名为「知墙」。

功能亮点

  • 四面便签墙：考研 / 学期 / 待办 / 生活
  • 作息侧栏 + 现有指针 + 明天预览
  • 课程表完整编辑：节次可增减、起止可改
  • 考试倒计时：多节点、里程碑变色
  • 便签盒 / 收纳箱：撕下、粘回、永久移除
  • 每日任务：撕掉后第二天自动贴回
  • AI 周报：支持本地 Ollama，Key 可脱敏导出
  • 桌面版：置顶 / 系统通知 / 自启 / 自动更新

SHA256 校验

Get-FileHash -Algorithm SHA256 .\MyMemoBoards-1.0.0-portable.exe

将输出与发布页 SHA256SUMS.txt 对比，一致后再运行。

提示：当前 exe 未做代码签名，Windows SmartScreen 可能提示「Windows 已保护你的电脑」。选择「更多信息 → 仍要运行」即可。

数据与隐私

  • 便签、作息、课程、设置只存本机
  • 浏览器版用 localStorage，桌面版存 exe 同目录 data/
  • AI 周报只在主动配置接口时发送到你自己填的 Base URL
  • 导出 JSON 默认文件名为「知墙-YYYY-MM-DD.json」，且 API Key 已脱敏；桌面版用 safeStorage 加密
