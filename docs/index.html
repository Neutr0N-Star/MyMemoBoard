手头

几件正在进行的事

需求、周报、杂活分墙放，做完撕下进盒，进度一直看得见。

它能做什么

便签墙可增删

可按需加墙、删墙、改名、拖顺序、设默认墙，复习、待办、生活分开贴。

贴、撕、粘

写上去是贴，做完撕下进便签盒，想恢复就粘回墙上。

今日时间轴

课表和作息按时间段叠在同一条轴上，重叠一眼可见——哪节课该去、哪段能空着，清清楚楚。

考试倒计时

顶栏并排多个考试节点（初试/复试/教资…），剩天数自动分档变色，越近越扎眼。

课程表

节次行数能加减，每节课起止时间随便改，改完立刻反映到时间轴；周课表、只读预览都有。

数据全在本机

默认不联网、不上云。数据全在本机，卸载可清干净；想备份就导出 JSON 或开自动备份。

课前与到期提醒

到点前弹系统通知——该上课了、考试和作业快到期限了，自动弹出提示框。

每周自己复盘

点一下，把这一周的便签、完成、逾期、考试揉成一份复盘——不用自己周末坐那回想这周干了啥。

接你自己的模型：填 Base URL 和 Key 就行，本地跑 Ollama 一分钱不花；Key 存在本机、加密，不外发。

不想接 AI 也完全没关系，它就是个便签墙，复盘是额外功能。
